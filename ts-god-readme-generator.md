# 🧠 GOD MODE TypeScript README Generator

## 🎯 Goal

Generate a **world-class, enterprise-grade README.md** with:

- Deep architecture analysis
- Automatic endpoint detection
- DTO/schema inference
- Mermaid diagrams
- Production-level documentation

This is **top 1% engineering documentation quality**.

- Parse routes (Express/Fastify)
- Detect:
  - endpoints
  - HTTP methods
  - params
  - middleware
- Infer DTOs from:
  - interfaces
  - validation schemas
  - request usage

### 🧠 2. Architecture Intelligence

Detect:

- Layered architecture
- Clean architecture
- Modular monolith
- Service boundaries

Explain:

- responsibilities
- coupling
- scalability risks

- Method

- Description (inferred)

- Params
- Body (DTO inferred)
- Response example
